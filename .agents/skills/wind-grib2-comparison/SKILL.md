# GRIB2風データ比較

地上10 mのU・Vを抽出して比較する作業を、再現可能な手順で実施する。データ取得、GRIB2復号、時刻対応、統計計算、作図、検証を分けて扱う。

## 実行条件を確定する

長時間処理を開始する前に、次の条件を確認または合理的に推定する。

- 製品名とデータ取得元
- 元データおよび出力時刻のUTC／JST
- 開始・終了時刻と1時間／30分間隔
- 地点名と緯度経度
- 鉛直面の条件（通常、地上10 mは面種別103・値10）
- 出力フォルダと必要な図・統計量

`FLA`を一般に通用する略語と決めつけない。設定上の製品ラベルとして扱い、実行記録には元の製品識別子を記載する。

## 取得方法を選ぶ

- ローカルの `.bin`、`.grb`、`.grib2`、`.grib` は、`scripts/grib2_wind.py`またはそのデコーダを利用する。
- FTP上の `.tar.bz2` は、先に `references/ftp-streaming.md` を読み、`scripts/stream_ftp_tar_uv.py` を出発点として利用する。
- 認証済みブラウザやプロキシ経由の取得コードは、Cookie、認証情報、ホスト名、絶対パスを公開コードから分離してから再利用する。

パスワード、セッションCookie、トークン、内部ホスト名、非公開URL、利用者固有の絶対パスをコミットしない。実行時引数または環境変数で渡す。

## GRIB2を復号して抽出する

GRIB2解析を変更するとき、または新しい製品に対応するときは、先に `references/grib2-wind-fields.md` を読む。

1. 完全なメッセージでは、`GRIB`、Edition 2、宣言されたメッセージ長、終端 `7777` を検証する。
2. Section 3を解析し、地点ごとの最近傍格子番号を計算する。
3. 繰り返されるSection 4～7を走査し、フィールドの固定順序に依存しない。
4. Uをカテゴリー2・パラメータ2、Vをカテゴリー2・パラメータ3として選択する。
5. 指定された鉛直面を要求し、地上10 mでは既定で面種別103・値10を用いる。
6. Section 7を復号する前に、Section 6のビットマップを格子番号へ適用する。
7. Section 5に従い、Template 5.0または5.3を復号する。
8. 1つのGRIBメッセージを破棄する前に、指定された全地点を抽出する。
9. 風速を `math.hypot(u, v)` で計算し、符号付きU・Vは変更せず保持する。

新しい製品を1年分処理する前に、ecCodesまたは信頼できる標本値と比較する。ファイル名や `GRIB` ヘッダーが一致するだけでは、対応テンプレートを正しく復号できる根拠にならない。

## 2製品の時刻を対応させる

共通する有効時刻・地点ごとに1行を作る。行番号で機械的に結合せず、一方にしかない行は診断情報として残す。

列名は、例えば次のように明示する。

```text
time,station,FLA_U_mps,FLA_V_mps,LFM_U_mps,LFM_V_mps
```

ファイル作成時刻や基準時刻だけでなく、有効時刻を記録する。タイムゾーン変換は一度だけ行い、列名と実行記録の両方にUTC／JSTを明記する。

## U・Vを別々に解析する

対応済みCSVには `scripts/compare_uv.py` を使用するか、次の定義を同じように実装する。

- 横軸を基準側の第1製品（通常FLA）とする。
- 縦軸を比較側の第2製品（通常LFM）とする。
- 点線の `x = y` と線形回帰直線を追加する。
- 各成分の図では、横軸・縦軸の範囲を同一にする。
- 回帰傾き、切片、Pearson相関係数、RMSE、MAE、誤差平均 `比較側 - 基準側` をCSVへ出力する。

指示がない限り、UとVの表示範囲まで同一にしない。V軸下限 `-15 m/s` などの明示的な指定を優先する。

## 完了報告前に検証する

`references/validation.md` を読み、少なくとも次を確認する。

- 期待時刻と抽出時刻
- 重複キーと欠測キーの件数
- 最近傍格子の緯度経度と地点からの距離
- U・Vが有限値であり、単位と値域が妥当であること
- 統計CSVと図が同じ対応データ件数を使用していること
- 回帰の横軸・縦軸と誤差の符号
- 出力ファイル名、タイムゾーン表記、期間の始端・終端

成果物フォルダを求められた場合は、そのフォルダに短い実行用READMEを作る。データ製品、地点座標、時刻基準、実行コマンド、出力、欠測、検証結果を記載する。このSkill自体にはREADMEを追加しない。

## 収録ファイル

- `scripts/grib2_wind.py`：対応する等緯度経度格子について、外部依存なしで復号・複数地点抽出を行う。
- `scripts/stream_ftp_tar_uv.py`：圧縮ファイルをディスクへ展開せず、FTP → bz2 → tar → GRIB2の順に逐次処理する。
- `scripts/compare_uv.py`：U・Vの回帰統計とSVG散布図を作成する。
- `assets/stations.example.csv`：地点入力CSVのひな型。
- `references/grib2-wind-fields.md`：フィールド選択、テンプレート、復号前提。
- `references/ftp-streaming.md`：FTPストリームの挙動と運用上の注意。
- `references/validation.md`：件数、時刻、格子、統計の検証項目。
- `references/skill-instructions-en.md`：本手順の英語版。
